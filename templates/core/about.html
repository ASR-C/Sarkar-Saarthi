{% if is_hindi %}हमारा उद्देश्य (The Problem & Vision){% else %}Why Sarkari Saathi Exists{% endif %}

They do this because official portals can be intimidating, instructions are often buried in dense bureaucratic English, and search engines are plagued with look-alike scam sites. {% endif %}

{% if is_hindi %} सरकार साथी का सिद्धांत स्पष्ट है: हम केवल शिक्षित और मार्गदर्शित करते हैं। हम कभी भी किसी नागरिक का फॉर्म स्वयं जमा नहीं करते और न ही कभी आपके आधिकारिक सरकारी लॉगिन या पासवर्ड को छूते हैं। {% else %} Sarkari Saathi's core principle is educational: We teach you how to fill your own forms safely on your smartphone. We never submit forms for you, and we never touch your government portal credentials. {% endif %}

{% if is_hindi %}1. डेटा न्यूनतमकरण (Data Minimisation){% else %}1. Minimal Data Collection{% endif %}

{% if is_hindi %} हम केवल आपका नाम, ईमेल पता (सत्यापन हेतु), पसंदीदा भाषा और राज्य संग्रहित करते हैं। हम कभी भी आधार नंबर, पैन नंबर, बैंक खाता संख्या, पासवर्ड या सरकारी ओटीपी नहीं मांगते और न ही संग्रहीत करते हैं। {% else %} We collect only your name, email (for verification), language, and state. {% if is_hindi %}2. फ़ाइल गोपनीयता (Private In-Browser File Tools){% else %}2. Zero-Server File Privacy{% endif %}

{% if is_hindi %} हमारे फोटो और हस्ताक्षर रीसाइज़िंग टूल्स पूर्णतः आपके फ़ोन के वेब ब्राउज़र में चलते हैं। आपकी व्यक्तिगत तस्वीरें या दस्तावेज़ कभी भी हमारे सर्वर पर अपलोड नहीं होते। {% else %} Photo and signature compression tools execute entirely in your local browser using client-side Web APIs. Your personal images never travel to or get saved on our servers. {% endif %}
